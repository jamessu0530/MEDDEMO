# 手機版情境驗收（2026-10-23）

主要流程可操作，驗收中修正登入返回、客戶入口返回、頻道附件搜尋返回及特大字體引導四類問題。此輪使用本機真實前後端與隔離示範資料庫，不是只檢查靜態原型。

## 已修正

| 情境 | 原本行為 | 修正後 |
| --- | --- | --- |
| 未登入直接開客戶網址，再登入或註冊 | 登入狀態更新時，頁面自動導向首頁，蓋過原目的頁 | 保留原目的頁與查詢參數；登入、註冊均實測通過 |
| 潛在銷售 → 客戶資料 → 返回 | 回到今日路線 | 回到潛在銷售 |
| 客戶清單 → 客戶 → 談判卡／錄音／取消新增訂單 | 子頁返回後遺失客戶檔案原本的返回位置 | 保留客戶檔案的入口 |
| 商品／潛在銷售 → 新增訂單 → 取消 | 回到訂單清單或客戶資料 | 回到原銷售分頁 |
| 頻道附件搜尋 → 原訊息 → 返回 | 關鍵字與搜尋範圍遺失 | 返回網址保留文字與範圍，重新取得搜尋結果；可重新整理 |
| 320 × 568、特大字體 → 使用說明 | 「下一步」位於 y=708，超出可見範圍 | 說明內容可捲動，底部操作固定可見；第一步按鈕 y=478～538 |

## 環境與驗收限制

原本開發資料庫版本為 `98b61d86e9cd`，程式要求 `30dc533d81d0`。原庫缺少 `channel.name`、`ask_record.inquiry_location` 等欄位，造成多頁 500；既有升級程式沒有這個來源版本的保留資料路徑，交易已回滾。因此另建 `meddemo_mobile_qa_20261023` 灌入目前版本的示範資料，再啟動 API 與背景工作驗收。原庫的升級問題仍待處理。

本機未設定地圖瀏覽器金鑰，實測的是無金鑰時的退路。此輪未驗證真實手機的麥克風／定位硬體、背景推播、外部日曆同步、Google／GitHub 授權，以及實際語音辨識準確度。錄音拒絕權限的錯誤提示已測。

附件的圖片搜尋返回目前只保存文字與頻道範圍，不會在網址中保存上傳圖片；影像搜尋的完整往返應另行驗收。這份結果不代表所有實機與外部服務均已驗證。
