# 吉祥物「熊熊滾」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把定案的吉祥物做成 React 元件，放進問答頁、等待與完成畫面、登入頁、導覽、找不到頁面、頻道的 AI 訊息與網站圖示。

**Architecture:** 一個 `Mascot` 元件輸出 inline SVG，七個狀態各對應一組 CSS keyframes（`mascot.css`，class 以 `mascot-` 開頭）。
形狀、顏色與 keyframes 照抄定案的設定稿。各頁面只決定「現在是哪個狀態、多大」。

**Tech Stack:** React 19、TypeScript、Tailwind、vitest（node 環境，用 `react-dom/server` 測輸出的 SVG）。

**Spec:** [docs/superpowers/specs/2026-09-30-mascot-design.md](../specs/2026-09-30-mascot-design.md)
**定案的造型與動畫（幾何、顏色、keyframes 的唯一來源）:** [docs/superpowers/specs/assets/2026-09-30-mascot-sheet.html](../specs/assets/2026-09-30-mascot-sheet.html)

## Global Constraints

- 三個顏色：主色 `#9B51E0`、淺紫 `#EADBFD`、深色 `#2B1B47`；舌頭 `#FF8FB3`；泡泡、聲波、點 `#C9A2F5`；星星 `#FFC93C`。不加漸層、描邊、其他元素。
- 沒有手、沒有領結、沒有尾巴、沒有腮紅、沒有高光。
- 半身特寫的畫布是 `24 16 192 192`，不畫影子。
- `prefers-reduced-motion: reduce` 時所有 `mascot-` 動畫停掉。
- 預設 `aria-hidden`；有 `label` 才是 `role="img"` 加 `aria-label`。
- 使用者看得到的文字用繁體中文；註解照現有檔案的語氣（中文、說明「為什麼」）。
- 不換按鈕自己的忙碌轉圈圈（登入、送出、GitHub 轉跳）。

**Interfaces:**

- [ ] **Step 1: 寫會失敗的測試**

`frontend/src/components/mascot.test.ts`（vitest 只收 `*.test.ts`，所以用 `createElement`，不寫 JSX）：

```ts
import { createElement } from "react"
import { renderToStaticMarkup } from "react-dom/server"
import { describe, expect, it } from "vitest"

import { Mascot, voiceMascotState, type MascotState } from "@/components/mascot"

const render = (props: Parameters<typeof Mascot>[0] = {}) => renderToStaticMarkup(createElement(Mascot, props))

describe("Mascot", () => {
  it("預設是待機、裝飾用，整隻都畫出來", () => {
    const svg = render()
    expect(svg).toContain('class="mascot mascot-idle"')
    expect(svg).toContain('viewBox="0 0 240 240"')
    expect(svg).toContain('aria-hidden="true"')
    expect(svg).toContain("mascot-shadow")
    expect(svg).toContain('data-eyes="open"')
    expect(svg).toContain('data-mouth="smile"')
  })

  it("每個狀態有自己的表情和道具", () => {
    const face: Record<MascotState, [string, string]> = {
      idle: ["open", "smile"], hi: ["happy", "open"], listen: ["open", "smile"], think: ["up", "hmm"],
      talk: ["open", "open"], wait: ["open", "smile"], yay: ["happy", "open"],
    }
    for (const [state, [eyes, mouth]] of Object.entries(face) as [MascotState, [string, string]][]) {
      const svg = render({ state })
      expect(svg, state).toContain(`mascot-${state}`)
      expect(svg, state).toContain(`data-eyes="${eyes}"`)
      expect(svg, state).toContain(`data-mouth="${mouth}"`)
    }
    expect(render({ state: "listen" }).match(/mascot-wave/g)).toHaveLength(2)
    expect(render({ state: "think" }).match(/mascot-dot/g)).toHaveLength(3)
    expect(render({ state: "wait" }).match(/mascot-load/g)).toHaveLength(3)
    expect(render({ state: "yay" }).match(/mascot-star/g)).toHaveLength(4)
    expect(render({ state: "idle" })).not.toMatch(/mascot-(wave|dot|load|star)/)
  })

  it("半身特寫切到頭和肩膀，不畫影子", () => {
    const svg = render({ bust: true, size: 28 })
    expect(svg).toContain('viewBox="24 16 192 192"')
    expect(svg).toContain('width="28"')
    expect(svg).not.toContain("mascot-shadow")
  })

  it("旁邊沒有文字說明時，用 label 讓讀屏唸得出狀態", () => {
    const svg = render({ state: "wait", label: "正在整理拜訪紀錄" })
    expect(svg).toContain('role="img"')
    expect(svg).toContain('aria-label="正在整理拜訪紀錄"')
    expect(svg).not.toContain("aria-hidden")
  })

  it("只用定案的那幾個顏色", () => {
    const colors = new Set(render({ state: "yay" }).match(/#[0-9A-Fa-f]{6}\b|#fff\b/g))
    expect([...colors].sort()).toEqual(["#2B1B47", "#9B51E0", "#EADBFD", "#FF8FB3", "#FFC93C", "#fff"].sort())
  })
})

describe("voiceMascotState", () => {
  it("AI 在講話就是回答，有查詢在跑是思考，其餘在聽", () => {
    expect(voiceMascotState("speaking", 0)).toBe("talk")
    expect(voiceMascotState("speaking", 2)).toBe("talk")
    expect(voiceMascotState("listening", 1)).toBe("think")
    expect(voiceMascotState("listening", 0)).toBe("listen")
  })
})
```

- [ ] **Step 3: 寫元件與動畫**

`mascot.tsx`：把設定稿 `<script>` 裡的 `bear()` 改寫成元件。形狀、座標、顏色逐一照抄；對應如下：

| 設定稿 | 元件 |
|---|---|
| `class="bear st-{x}"` | `class="mascot mascot-{x}"`（`st-hi`→`mascot-hi`，其餘同名） |
| `b-shadow`、`b-all`、`b-body`、`b-ear-l`、`b-ear-r`、`b-face`、`b-eyes`、`b-mouth` | `mascot-shadow`、`mascot-all`、`mascot-body`、`mascot-ear-l`、`mascot-ear-r`、`mascot-face`、`mascot-eyes`、`mascot-mouth` |
| `x-wave w1/w2`、`x-dot d1..d3`、`x-load p1..p3`、`x-star s1..s3` | `mascot-wave`、`mascot-dot`、`mascot-load`、`mascot-star`，順序用 `data-n="1".."4"` |
| `EYES.open/up/happy`、`MOUTH.smile/hmm/open` | 同樣的三種眼睛與三種嘴；群組加 `data-eyes`、`data-mouth` |
| `o.bust` | `bust`：`viewBox="24 16 192 192"`、不畫影子 |

狀態決定表情：`idle`/`listen`/`wait` 是 `open`+`smile`；`think` 是 `up`+`hmm`；`talk` 是 `open`+`open`；`hi`/`yay` 是 `happy`+`open`。
道具：`listen` 兩道聲波、`think` 三顆泡泡、`wait` 三顆點、`yay` 四顆星星（座標照設定稿的 `WAVES`、`DOTS`、`LOAD`、`STARS`）。

```tsx
export function voiceMascotState(status: "listening" | "speaking", pending: number): MascotState {
  if (status === "speaking") return "talk"
  return pending > 0 ? "think" : "listen"
}
```

`mascot.css`：把設定稿 `<style>` 裡 `.bear …` 之後的規則照抄，class 依上表改名，`.x-wave.w2` 這類改成 `[data-n="2"]`，
keyframes 名稱加上 `mascot-` 前綴。最後加：

```css
/* 系統設定「減少動態效果」：停在該狀態的表情，不動 */
@media (prefers-reduced-motion: reduce) {
  .mascot, .mascot * { animation: none !important; }
}
```
