# 熊熊滾收藏與換裝

2026-10-14

熊熊滾維持原本的圓潤輪廓，增加異色、縣市限定服裝、收藏與頭像；手持道具款加上同色小熊掌。入口在個人頁與帳號設定，頁面 `/mascots`。
互動預覽：[熊熊滾衣櫃](assets/2026-10-14-mascot-wardrobe.html)，執行 `npm --prefix frontend run mascot-wardrobe-sheet` 重建。

## 蒐集與穿搭

- 一開始有經典紫、原本的熊熊、雲朵圍巾、小畫家貝雷帽；2026-10-23 新增護士帽、拿針筒、頭頂藥丸、領帶、提公事包、拿扳手六款日常造型，在「服裝」分頁直接選用。
- 到過路線上該縣市的任一站，永久收藏該縣市服裝。先支援座騎圖鑑的七個縣市：台北小籠包、新北天燈、新竹貢丸、台中珍奶、彰化肉圓、台南虱目魚、高雄香蕉。
- 異色有薄荷星光、蜜桃泡泡、午夜銀河、奶油星星。連點六下分裂時，伺服器以 1/8 機率抽到其中一款；七次沒有遇到時，第八次保底。重複遇到同款不重複入庫。
- 色彩與服裝可自由混搭。未收藏也可以試穿，換上與設為頭像兩個操作只允許已收藏的組合。
- 穿搭與收藏跟真正登入帳號走。代理示範業務時，縣市進度來自示範路線，但異色、服裝與頭像存在自己的帳號。
- 在衣櫃設定熊熊頭像後，個人頁、頻道、成員列表等共用的 `UserAvatar` 會同步。上傳照片會切回照片；取消熊熊頭像不刪收藏或穿搭。

## 保存與 API

- `mascot_wardrobe`：目前色彩、服裝、是否作為頭像、異色保底次數。
- `mascot_collectible`：登入帳號 × 收藏品，保留第一次取得時間。
- `mascot_encounter`：登入帳號 × 分裂 UUID，每次事件抽選一次；重送返回同樣結果。
- 三表透過外鍵隨帳號刪除；部署重新灌展示資料時由 `KEPT_SETTINGS` 留下收藏與穿搭。
- `GET /api/mascot` 同步已到站的縣市收藏並回傳衣櫃；到站 API 也同步，先取得的款式不因重置行程消失。
- `POST /api/mascot/encounters` 僅收 UUID，不接收前端指定的稀有色或機率。每帳號列鎖保護同時抽選與換裝。
- `PUT /api/mascot/equip` 驗證組合與所有權，保存穿搭與頭像選擇。
- `/api/avatars` 同時回傳照片網址與 `mascot_avatars`；換裝後沿用既有 avatars 即時通知。

既有資料庫只補表，不需清掉資料：

```sh
uv run --project backend python backend/scripts/create_mascot_tables.py
```

色票與服裝目錄在前後端各留一份 JSON，讓前端獨立的 Docker 建置能運作；後端測試比對兩份目錄一致。
衣服跟熊身體一起做動畫；支援半身頭像、系統減少動態效果、鍵盤操作。手機為一欄，寬桌機為試穿與收藏兩欄。

## Three.js 立體舞台

衣櫃預設用立體舞台，可切換回平面。`mascot-3d-scene.ts` 以 SVGLoader 讀取同一份熊熊與服裝輪廓，擠出厚度、加上圓角及柔和光影；六款日常造型與手持熊掌也沿用同一份 SVG。
支援拖曳轉身與自然呼吸、眨眼；連點六下會有粒子炸開與兩隻小熊彈出的效果，同樣呼叫收藏 API。不顯示指定動作或正背面切換按鈕。

2026-10-16：立體熊熊屁股後側加入三條圓頭短線組成的小星號，沿用各異色的深色；披風會自然遮住標記。想看背面直接拖曳熊熊，不另外放操作按鈕。
眼睛與反光以兩眼中心為軸一起開合，待機每 5.6 秒連眨兩下，主動眨眼立即開始、每 2.4 秒重複；閉眼的打盹與伸懶腰維持原表情。
記憶看板的立體熊熊同步加入後側小星號及自然眨眼；系統開啟「減少動態效果」時停止眨眼。
拖曳不累積戳戳次數，鍵盤可以操作戳戳與動作按鈕。WebGL 不可用時顯示 SVG；減少動態效果時停止自動動畫。
舞台只開一個 WebGL context，只有使用立體模式才載入 Three.js；切換穿搭或離開時釋放模型、材質與 context，畫面隱藏時停止繪製。
頭像仍用同色彩與同服裝的 SVG 特寫，讓頻道的小頭像保持清楚。
