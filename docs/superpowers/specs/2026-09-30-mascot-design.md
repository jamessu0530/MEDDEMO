# 吉祥物「熊熊滾」

2026-09-30

AI 助理的吉祥物：一隻紫色、站著的小熊，叫「熊熊滾」。AI 在聽、在想、在回答、在處理的時候，用牠的動作告訴使用者，
取代現在的轉圈圈和麥克風圖示。定案的樣子與動畫見 [assets/2026-09-30-mascot-sheet.html](assets/2026-09-30-mascot-sheet.html)
（用瀏覽器打開就會動）。

## 為什麼做

- App 裡「AI 正在做事」現在只有轉圈圈和一行字，看不出是在聽、在查，還是在講。
- 頻道第 3 階段 AI 主理會在頻道裡發言，需要一個認得出來的頭像。
- 沒有任何品牌圖像：網站圖示是一塊紫色方塊，登入頁只有文字。

## 已定案的決定

1. **紫色的熊，站姿，頭和身體是同一個高高的圓角形**，底下分出兩條短腿。不是球形。
2. **沒有手**。每個狀態只靠身體的姿勢、耳朵、眼睛和嘴巴表現。
3. **元素最少**：身體、兩隻耳朵、眼睛、鼻吻、鼻子、嘴，共七個形狀。不要領結、尾巴、腮紅、高光。
4. **平塗、不描邊、沒有漸層**，三個顏色。做法參考 Duolingo（只用圓形與圓角形狀、用最少的形狀、輪廓一眼認得出來）
   與 Microsoft Copilot 的 Mico（用狀態的變化讓人知道 AI 現在在聽、在想還是在回答）。
5. **名字叫熊熊滾**。
6. **用 SVG 加 CSS 動畫做成 React 元件**，不引入 Rive、Lottie 這類動畫套件：形狀只有七個，動畫都是位移、旋轉、縮放。

## 造型

畫布 `0 0 240 240`，腳踩在 y=215，地上有一塊淡淡的影子。

| 部位 | 形狀 | 顏色 |
|---|---|---|
| 身體（含頭與腿） | 一條路徑：上緣圓頂，兩側直下，底下兩條短腿、中間拱起 | 主色 `#9B51E0` |
| 耳朵 | 兩個圓，圓心 (80, 62)、(160, 62)，半徑 22；裡面各一個半徑 10.5 的圓 | 主色；耳內 `#EADBFD` |
| 眼睛 | 兩個直橢圓，各帶一顆白色反光 | `#2B1B47` |
| 鼻吻 | 一個橫橢圓 | `#EADBFD` |
| 鼻子 | 圓角倒三角 | `#2B1B47` |
| 嘴 | 一條短直線接一個「ω」；張嘴時是深色的半圓加粉紅色舌頭 | `#2B1B47`；舌頭 `#FF8FB3` |

臉的中心在 (120, 120)。「思考」的泡泡、「聆聽」的聲波、「等待」的三顆點用淺紫 `#C9A2F5`；
「完成」的星星用黃色 `#FFC93C`，是整隻熊唯一用到紫色以外的顏色。

**半身特寫**：頭像與網站圖示用，畫布切成 `24 16 192 192`（頭到肩膀），不畫影子，放在淺紫 `#EADBFD` 的圓或圓角方塊裡。

## 狀態

每個狀態是一組循環動畫。

| 狀態 | `state` | 動作 | 眼睛／嘴 |
|---|---|---|---|
| 待機 | `idle` | 呼吸；連眨兩下；右耳抖一下；左右張望 | 張開／微笑 |
| 打招呼 | `hi` | 左右探頭加小跳，兩隻耳朵輪流擺 | 笑到瞇起來／張嘴 |
| 聆聽 | `listen` | 歪頭；右耳豎起來變大；聲波從右邊進來 | 張開／微笑 |
| 思考 | `think` | 身體慢慢左右晃；三顆想法泡泡依序冒出來 | 往右上看／小圓嘴 |
| 回答 | `talk` | 嘴巴開合；身體跟著點 | 張開／張嘴 |
| 等待 | `wait` | 左右腳輪流踏步；耳朵跟著擺；頭上三顆點輪流跳 | 張開／微笑 |
| 完成 | `yay` | 蓄力下壓、跳起拉長、落地壓扁、回彈；耳朵慢半拍；四顆星星彈出來 | 笑到瞇起來／張嘴 |

半身特寫裡聲波、泡泡、點、星星會被切掉，只剩臉、耳朵與身體的動作，這是預期的：頭像太小，那些東西本來就看不清楚。

系統設定「減少動態效果」（`prefers-reduced-motion`）時所有動畫停掉，只顯示該狀態的表情。

## 放在哪裡

| 畫面 | 位置 | 狀態 | 大小 |
|---|---|---|---|
| 問答頁：語音 dock | 取代麥克風圓鈕裡的圖示，外圈照舊跟著音量放大 | AI 在講話 `talk`；查詢中 `think`；其餘 `listen` | 半身 48 |
| 問答頁：查詢進行中 | 取代「思考要怎麼查…」「送出查詢…」前面的轉圈圈 | `think` | 半身 28 |
| 問答頁：還沒有對話 | 範例問題上方 | `hi` | 全身 96 |
| 拜訪整理中（`/visits/:id` 處理中） | 取代轉圈圈 | `wait` | 全身 140 |
| 回寫完成 | 三套系統都寫入時取代打勾圖示；沒寫完照舊用警示圖示 | `yay` | 全身 96 |
| 登入頁 | 標題上方 | `hi` | 全身 96 |
| 首頁（今日路線） | 右下角、底部分頁列上方的圓鈕，點了進問答頁 | `idle` | 全身 62，白底圓鈕 64 |
| 首次使用的導覽 | 取代每一步的大圖示，原本的圖示縮成右下角的小徽章 | 第 1 步 `hi`、第 2 步 `listen`、第 3 步 `think` | 全身 128 |
| 找不到頁面 | 說明文字上方 | `think` | 全身 96 |
| 頻道：AI 主理的訊息 | 訊息左邊的頭像 | `idle` | 半身 28 |
| 網站圖示 | `index.html` 的 favicon | 靜態 | 半身，淺紫圓角方塊底 |

其他轉圈圈（登入按鈕、送出按鈕、GitHub 登入轉跳）不換：那些是按鈕自己的忙碌狀態，不是 AI 在做事。

## 元件

`frontend/src/components/mascot.tsx`：

```tsx
type MascotState = "idle" | "hi" | "listen" | "think" | "talk" | "wait" | "yay"

<Mascot state="think" size={28} bust />
<Mascot state="wait" size={140} label="正在整理拜訪紀錄" />
```

- `state` 預設 `idle`；`size` 是邊長（px）；`bust` 是半身特寫。
- 預設是裝飾（`aria-hidden`）。旁邊沒有文字說明狀態時傳 `label`，會變成 `role="img"` 加 `aria-label`。
- 動畫寫在 `frontend/src/components/mascot.css`，由元件自己 import；class 都以 `mascot-` 開頭，不跟 Tailwind 撞名。
- 語音 dock 的狀態對應寫成一個純函式 `voiceMascotState(status, pending)`，好測。

## 測試

vitest 的環境是 node，沒有瀏覽器。用 `react-dom/server` 的 `renderToStaticMarkup` 測元件產生的 SVG：

- 每個狀態掛上對應的 class，眼睛與嘴是該狀態的樣子（例如 `think` 沒有微笑的嘴、有三顆泡泡）。
- `bust` 切成 `24 16 192 192`、不畫影子。
- 預設 `aria-hidden`；有 `label` 時是 `role="img"` 加 `aria-label`。
- `voiceMascotState`：講話中是 `talk`，有查詢在跑是 `think`，其餘是 `listen`。

動畫本身靠實際打開 App 看。

## 不在這次範圍

- Rive、Lottie，或跟語音音量同步的嘴型。
- 音效。
- 主管端、組織管理頁、頻道列表的空白狀態。
- 記憶看板（頻道第 2 階段）裡的吉祥物。
- App 主畫面圖示（PWA manifest）。
