# 問答 3D 記憶地圖

問答頁 `/ask` 的「記憶地圖 · 3D」入口，參考去趣 `demo-repository/frontend/app/components/MemoryGraph3D.client.vue` 的獨立視窗、旋轉、縮放與節點查看互動。

地圖使用同一份打字／語音對話 store。顯示問題、查詢類型、實際引用的公司文件、網路資料、頻道重點、附件、查詢結果與相關客戶。相同文件段落或附件共用節點，連線表示查詢、引用與來源關係，不另外猜測內容之間的語意關係。

- 中心使用依既有「熊熊滾」輪廓建立的 3D 模型，包含圓角身體厚度、立體耳朵與附著在正面的五官。模型和節點、連線共用 Three.js 場景與旋轉，能查看側面及背面，縮放也一起改變大小。查詢進行中顯示思考表情，查完回到待機；點選中心可查看、編輯或刪除中心節點。
- 查詢進行中以藍色標示問題及連線，顯示最新查詢步驟；答完、失敗或等待選擇類型時同步更新。
- 支援全部、這一題、查數字、查規定、查頻道篩選與節點搜尋。搜尋保留相鄰問題／依據，篩選後自動調整視角。
- 點節點看完整問題、進度、回答或依據；「回看這題」關閉視窗並捲回原回答。客戶、網頁出處與可讀的原始附件頻道提供原有導覽入口。
- 節點可編輯名稱與個人筆記，筆記也能搜尋。刪除節點移除地圖上的節點與連線，原查詢與引用資料保留；提供單筆復原及還原全部。改名、筆記與刪除紀錄存在同一段問答 session，關閉地圖、切頁保留，換帳號或重新整理清空。
- Three.js 只在開啟地圖後下載；拖曳旋轉、滾輪或雙指縮放，也可用方向鍵、加減鍵和 Home 操作。
- WebGL 無法使用或 context 遺失時提供節點清單及重試。動態模組下載失敗則提示重新整理會清空對話。關閉視窗會釋放 renderer、幾何、材質、事件與 animation frame；減少動態設定停用流光與脈動。
- 沿用現有帳號權限與對話生命週期，不新增資料查詢或儲存。切換頁面保留；登出、換人或重新整理清空。地圖顯示最近 24 題，頁面回答仍保留完整對話。

開發預覽：啟動 Vite 後開啟 `/memory-map.html`。此頁明確標示示範資料，不呼叫 AI，不讀取帳號；提供已回答、正在查詢、空白對話三種狀態。開啟地圖後按 F9 可模擬 WebGL context 遺失。

驗證：`src/ask/memory-map.test.ts` 涵蓋共用引用、查詢狀態、篩選／搜尋、實際依據、附件來源限制及 24 題上限。另以桌面 1280×800、手機 390×844 實際驗證關聯、搜尋無結果、旋轉、聚焦、回看、空白狀態、WebGL 降級與重試。

Apple 設計參考：[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Color](https://developer.apple.com/design/human-interface-guidelines/color)。這是套用其層次與材質原則的原創網站介面：系統字體、霧白內容畫布、低飽和分類色、單一藍色焦點，浮動控制列使用半透明材質，文字內容面板維持清楚的實色背景。支援深色配色、減少透明度、提高對比與減少動態偏好。

新增的 `src/ask/memory-map-edits.test.ts` 與問答 session 測試涵蓋編輯保留原引用、進度更新後保留筆記、刪除與復原、搜尋筆記、分類節點刪除後的篩選，以及帳號間的狀態隔離。
